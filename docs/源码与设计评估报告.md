# 源码与设计评估报告

> 项目：老人提醒软件 · 评估日期：2026-10-31
> 评估对象：`老人提醒软件.docx`（设计方案）、`elder_voice_reminder_source.zip`（源码工程）、`界面2.png`（8屏UI稿）、`图标1.png`（应用图标）

## 一、设计方案核心需求（来自 docx）

| # | 需求 | 说明 |
|---|------|------|
| 1 | **一键录音→语音转文字** | 老人只说一句话，自动生成提醒内容 |
| 2 | **两种提醒方式** | ① 滴滴滴提示音 ② 语音播报“到点了，请注意！”重复约2分钟 |
| 3 | **到点最大音量** | 尝试把闹钟通道音量调最大 |
| 4 | **查看/管理提醒** | 查看内容、编辑、删除、停用/启用 |
| 5 | **周期提醒** | 常用事项勾选作为周期提醒（每天/每周/每月/自定义间隔） |
| 6 | **语音修改** | 已有提醒可用语音改时间/内容 |
| 7 | **设计原则** | 老人不用打字、不用复杂菜单，一个大按钮走完全流程 |

## 二、你额外强调的 2 点硬性要求

1. **必须自带语音识别软件** —— 不依赖手机系统是否装了语音服务，软件内嵌离线语音识别引擎。
2. **锁屏 / 使用其他软件时提醒务必实现**：**声音 + 图片**，全屏弹出**界面2第8屏的红色提醒界面**（到点了，请注意！+ 红色背景 + 停止提醒按钮）。

## 三、现有源码能力盘点（elder_voice_reminder）

**技术栈现状**：Kotlin 2.1.20 + AGP 8.9.2，传统 View（LinearLayout/Button），minSdk 26 / targetSdk 35，SharedPreferences 本地存储，AlarmManager 定时。**无 Gradle Wrapper JAR**（README 明示当前不能直接跑 `gradlew`）。

### 已实现（方向正确）
- ✅ 大按钮语音录入（调用系统 `RecognizerIntent`）
- ✅ 中文时间解析（今天/明天/后天、上午/下午、三点/15点、半）
- ✅ 语音/滴滴滴两种提醒模式，TTS 播报“到点了，请注意！”约2分钟
- ✅ 全屏提醒 Activity：`setShowWhenLocked` + `setTurnScreenOn` + 锁屏显示
- ✅ 到点尝试把闹钟音量调最大
- ✅ 单次/每天/每周周期；重启/升级/时间变化后恢复闹钟（BootReceiver）
- ✅ 编辑/删除/停用；权限引导对话框

### 与需求的关键差距

| 差距项 | 现状 | 需求 | 影响 |
|--------|------|------|------|
| **① 离线语音识别** | 系统 `RecognizerIntent`，**不捆绑模型**，手机没装语音服务就不能用 | **自带**识别引擎，离线可用 | 🔴 你强调的重点，必须重做 |
| **② 全屏红色提醒界面** | AlarmActivity 是深蓝背景、白色文字 | 界面2第8屏：**红色背景 + 铃铛 + 提醒内容卡片 + 停止提醒** | 🔴 你强调的重点，必须重做 |
| **③ 应用图标** | 无 `ic_launcher` 资源 | 用**图标1**（蓝底铃铛爱心时钟）做自适应图标 | 需切图 |
| **④ UI 整体** | 简陋 LinearLayout，与8屏设计差异大 | **严格按界面2的8屏**（首页/语音录入/确认/提醒列表/新增/设置周期/编辑/到点提醒） | 🔴 需整体重做 |
| **⑤ 底部导航** | 无 | 首页 / 全部提醒 / 常用（界面2有） | 需新增 |
| **⑥ 周期提醒** | 仅每天/每周 | 每天/每周/**每月**/自定义间隔 | 需增强 |
| **⑦ 常用事项模板** | 无 | 常用事项可勾选快速创建 | 需新增 |
| **⑧ 语音修改入口** | 有 `handleSpeech` 逻辑但无入口 | 界面2第7屏有“语音修改”大按钮 | 需补 UI |
| **⑨ 构建能力** | 无 Gradle Wrapper | 可命令行/CI 构建 | 需补 wrapper |

## 四、总体结论

- 当前源码是**可运行的基础骨架**，方向正确，但**离你的正式需求（界面2 + 自带离线识别 + 红色全屏提醒）有较大距离**。
- 建议**保留现有核心逻辑**（提醒调度、TTS、时间解析、存储、重启恢复），**UI 层按界面2重做**，并**内嵌离线语音识别引擎**。
- 源码工程未在此环境编译过，需补 Gradle Wrapper 并配置 Android SDK 后实际构建、真机测试。
