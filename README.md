# 老人提醒软件

> 面向家里老人的安卓语音提醒助手
> 使用场景：安卓智能手机 / 折叠屏（暂不考虑平板）
> 技术栈：Kotlin + Jetpack Compose + sherpa-onnx 离线语音识别

## 一、当前版本已实现

| 功能 | 状态 |
|------|------|
| 一键语音录入，**内置离线中文识别**（sherpa-onnx，随 APK 打包，无需联网） | ✅ |
| 语音内容自动解析日期/时间（今天/明天/后天/周几/上午下午晚上/几点几分） | ✅ |
| 识别结果确认页（确认保存 / 重新说一遍） | ✅ |
| 两种提醒方式：语音播报“到点了，请注意！” / 滴滴滴提示音 | ✅ |
| **锁屏、后台、其他应用前台时全屏红色提醒**（界面2 第8屏样式） | ✅ |
| 到点自动把闹钟音量调到最大 + 震动 | ✅ |
| 提醒列表（全部/今天/未来/已完成）、开关、编辑、删除 | ✅ |
| 周期提醒：不重复 / 每天 / 每周（多选星期）/ 每月 / 自定义间隔 | ✅ |
| 常用事项模板一键添加 | ✅ |
| 语音修改（对已有提醒重新说出内容） | ✅ |
| 重启手机、应用升级、系统改时间后自动恢复提醒 | ✅ |
| 应用图标（自适应图标，来自“图标1”） | ✅ |

## 三、构建 APK

环境要求：JDK 17、Android SDK Platform 35、Build-Tools 35。

```bash
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

> 国内网络已在 `settings.gradle.kts` 配置阿里云镜像。

## 四、安装后必做设置（重要）

1. 允许**通知**权限（Android 13+）
2. 允许**全屏提醒**（设置 → 应用 → 特殊权限）
3. 允许**精确闹钟**
4. 电池设置改为**不限制 / 允许后台运行**
5. 把**闹钟音量**调大
6. 用应用内“设置”页创建一条 2 分钟后测试提醒，锁屏验证

> 各厂商（小米/华为/OPPO/vivo）菜单名称不同，建议在目标手机上逐项确认。

## 五、已知限制

- 语音识别模型为流式轻量版（约 25MB），准确率优先保证常见生活用语与时间表达；若实测不理想，可替换为更大的模型或切换到 Vosk（引擎已做隔离封装，替换成本低）。
- 语音播报使用系统 TTS；个别设备缺中文语音包时会自动降级为滴滴滴提示音。
- Android 14+ 对全屏通知有系统级限制，需用户手动授权；已提供引导入口。
